Lässt sich OneDrive komplett von einem Windows 8/8.1-Rechner entfernen? Immer häufer wird uns diese Frage von unseren Kunden gestellt. OneDrive (also der online Speicherdienst von Microsoft, welcher noch bis vor kurzem SkyDrive hieß) ist seit Windows 8 ein fester Bestandteil von Windows und somit kommt jeder Computernutzer, der von auf Windows 8 umsteigt oder sich einen neuen Computer kauft, zwangsläufig damit in Berührung. Insbesondere die Integration von OneDrive in Microsoft Office, wo OneDrive normalerweise als Standardspeicherort vorgeschlagen wird, geht vielen Nutzern auf die Nerven.

Dieser Artikel bietet zwar keine Schritt-für-Schritt-Anleitung zum Entfernen von OneDrive, aber er zeigt einen Weg, wie man sich mit der Präsenz von OneDrive auf seinem Rechner eventuell ein bisschen eher anfreunden kann.

OneDrive entfernen

Zum derzeitigen Zeitpunkt ist uns gar nicht bekannt, ob sich OneDrive restlos entfernen lässt. Microsoft hat sich viel Mühe gegeben, OneDrive tief im System zu verankern, um genau diesem Bestreben vorzubeugen. (Sobald wir mehr wissen, werden wir es hier im Wissensbereich natürlich posten.)

Die hier präsentierte Anleitung adressiert die Integration von OneDrive in Microsoft Office. Genauer: Sie erläutert, wie man OneDrive als Standardspeicherort in den einzelnen Office-Programmen ablösen kann.

Öffnen Sie Word, Excel, Powerpoint oder einen beliebigen anderen Bestandteil von Microsoft Office. Dann führen Sie bitte in den „Speichern“-Optionen (Tab Datei > Menüpunkt Optionen > Navigationspunkt Speichern) folgende zwei Aktionen aus:

  1. Entfernen des Häkchens bei „Zusätzliche Speicherorte anzeigen, auch wenn eine Anmeldung erforderlich ist“ und
  2. Setzen des Häkchens bei „Standardmäßig auf Computer speichern“.

In jedem Office-Programm, in dem Sie OneDrive nicht mehr als Standardspeicherort haben wollen, müssen Sie dies machen.

Das Ergebnis

Wenn Sie von nun ab in den Office Programmen in das Speichern-Menü gehen, dann werden Ihnen standardmäßig Ihre Ordner auf der lokalen Festplatte angezeigt. OneDrive (aka SkyDrive) kann man immer noch nutzen, indem man zum entsprechenden Ordner navigiert, aber es drängt sich nicht mehr so penetrant in den Vordergrund.
