In den letzten Tagen erhielten wir einige Anrufe von verunsicherten Windows 7 und Windows 8 Benutzern aufgrund einer kostenlosen Upgrade-Möglichkeit auf Windows 10. Die Verunsicherung war aufgekommen, weil plötzlich ein Fenster erschien, in denen unseren Kunden ein kostenloses Upgrade auf Windows 10 angeboten wurde. Dieses Angebot ist jedoch kein Virus oder Trojaner sondern ein aktuelles Angebot von Microsoft, um möglichst schnell viele Benutzer für einen Wechsel zum neuen Betriebssystem zu motivieren. Lesen Sie hier die sechs wichtigsten Dinge, die Sie schon heute über Windows 10 wissen sollten.

1. Wann erscheint Windows 10?

In einem Blogeintrag hat Windows-Chef Terry Myerson den 29.Juli 2015 als Veröffentlichungsdatum bestätigt. Jedoch war dies keine große Überraschung mehr, nachdem dieser Termin schon mehrfach von Branchenkennern wie z.B. der AMD Chefin Lisa Su genannt wurde.

2. Warum gibt es kein Windows 9?

Offiziell heißt es aus Redmond, dass Windows 10 so viele Neuerungen enthalte, dass man einfach direkt eine Nummer überspringen musste.
Aus inoffizieller Quelle heißt es jedoch, dass man aus Angst vor Inkompatibilitäten mit älterer Software lieber die 9 übersprungen hat. Mit Windows 95 und 98 gebe es gleich zwei alte Windows-Betriebssysteme, die eine 9 im Namen tragen und somit dazu führen könnten, dass schlecht programmierte Software glaubt, ein vollkommen veraltetet Betriebssystem vor sich zu haben. Diese Erklärung klingt irgendwie zu plausibel, als dass man Sie direkt als Gerücht abtun sollte.

3. Warum und wie lange ist Windows 10 kostenlos?

Das Upgrade auf Windows 10 ist für alle Besitzer von Windows 7 und Windows 8 für ein Jahr ab dem Veröffentlichungsdatum kostenlos. Konkret also vom 29. 06. 2015 bis 28. 06. 2016. Alle, die noch Windows XP oder Windows Vista einsetzen, werden den vollen Kaufpreis zahlen müssen.
Mit dem kostenlosen Upgrade will Microsoft alle Windows 7 Benutzer davon überzeugen, zu Windows 10 zu wechseln. Unter allen Umständen will Microsoft kein zweites Windows XP – ein veraltetes System, das dennoch viele Anwender weiter nutzen, weil Sie keinen Wechselbedarf sehen. Zu gut errinnern sich die Führungskräfte von Microsoft noch an den Aufschrei, als die Sicherheitsupdates für Windows XP am 8. April 2014 eingestellt wurden.


Bild: So sieht das Angebot von Microsoft für ein kostenloses Upgrade auf Windows 10 aus

4. Wird Windows 10 die letzte Windows Version sein?

Nach den Plänen von Microsoft werden zukünftig großen Versionssprünge von Windows der Vergangenheit angehören. Nach dem Vorbild von Linux und Mac OS wird es eine Windows Basis geben, die kontinierlich mit Updates erweitert wird. Auf lange Sicht wird Microsoft daher dafür sorgen, dass die Zahl aus dem Produktnamen verschwindet und das Betriebssystem nur noch „Windows“ heißt.

5. Was kann Windows 10?

Es gibt kein Killerfeature, das ein sofortiges Upgrade auf Windows 10 notwendig macht. Trotzdem gibt es vier Dinge, die man besonders erwähnen sollte:

  • Windows erhält seinen Startbutton zurück. Wir sind gespannt, ob dieser besser angenommen wird als das neue Kacheldesign von Windows 8.
  • Apple hat Siri, Google hat Now, Amazon hat Echo und Windows hat zukünftig einen Sprachassistenten mit Namen Miranda.
  • Ein Browser mit Namen Spartan wird in Windows 10 den Internet Explorer ergänzen. Dieser soll besonders schnell und sicher sein.
  • Windows 10 wird auf allen Plattformen (Mobil, Notebook und Desktop) laufen. Dadurch sollen Programme schneller auf allen Plattformen verfügbar sein.

6. Wann sollte man umsteigen?

Wir raten erst mal zur Geduld. Das Upgrade auf Windows 10 wird ein Jahr lang kostenlos sein und üblicherweise empfiehlt es sich erst dann das System zu wechseln, wenn die ersten Kinderkrankheiten ausgebügelt sind.
