Microsoft macht es Käufern einer Upgradelizenz nicht leicht, ein aktuelles Betriebssystem zu installieren. Wenn Sie z.B. als Käufer einer Upgradelizenz für Windows 8 eben dieses Betriebssystem auf Ihren Rechner neu installieren wollen, dann müssen Sie zuerst Windows 7 installieren, dann auf Windows 8 upgraden und erst dann können Sie den Sprung auf Windows 8.1 vornehmen. Dass so ein Vorgang auch einen ganzen Vormittag andauern kann, obwohl es viel schneller gehen könnte, ist mehr als nur ärgerlich. In diesem Artikel zeigen wir Ihnen, wie Sie ohne diesen Update-Wahnsinn auf legalem Wege zu einer Windows 8.1 Neuinstallation kommen.

Das Grundproblem: Unterschiedliche Lizenzen für Neuinstallationen und Upgrades von Windows 8

Die Zeiten, in denen man jährlich sein Windows neu installiert hat, um ein sauberes Windows zu haben, sind vorbei. Windows ist mittlerweile so stabil und mit ausreichend Selbstheilungskräften ausgestattet, dass man Windows 7 und 8 ruhigen Gewissens mehrere Jahre laufen lassen kann. Dem ungeachtet fällt es schwer, die Lizenzpolitik von Microsoft zu verstehen. Die Verkaufszahlen von Windows 8 wurden zur Veröffentlichung massiv mit vergünstigten Upgradelizenzen gepusht, wobei diese Lizenzschlüssel auch wirklich nur für ein Upgrade gültig sind. Windows 8 verweigert die direkt Neuinstallation von Windows 8 mit so einem Lizenzschlüssel mit dem Hinweis, dass die Lizenz dafür nicht gültig ist. Natürlich haben findige Leute eine Lösung gefunden, wie es trotzdem funktioniert, jedoch war dieser Weg alles andere als bequem und benötigte viele manuelle Eingriffe.

Microsoft hat ein Einsehen

Trotz der massiven Kritik von Seiten der Medien – allen voran der Computerzeitschrift c’t – verfolgt Microsoft seit Windows 7 dieses kundenunfreundliche Lizenzverfahren. Auch bot Microsoft bis vor wenigen Monaten keine offiziellen Installationsimages zum Downloads an. Doch anscheinend hat Microsoft ein Einsehen, denn mittlerweile gibt es die offizielle Downloadseite von Microsoft und auch einen legalen Weg, um mit der Upgradelizenz zu einer Neuinstallation zu kommen.

Schritt 1: Installation von Windows 8.1 mit einer generischen Lizenz

Als Erstes laden Sie sich an einem beliebigen Windows Rechner die Windows 8.1 Installationsvorbereitungsdatei von der offiziellen Downloadseite von Microsoft herunter. Wenn der Download abgeschlossen ist, stecken Sie einen mindestens 4 Gigabyte großen USB-Stick an diesem Rechner an und starten Sie die Datei. Wählen Sie „Installationsmedium erstellen“ und wählen Sie danach den USB-Stick aus. Warten Sie, bis der USB-Stick zu einem Windows 8.1 Installationsmedium gemacht wurde. Danach können Sie mit dem Stick jeden beliebigen Rechner neu installieren.

Bei der Abfrage nach dem Lizenzschlüssel tragen Sie nicht Ihren Upgradelizenzschlüssel ein, sondern verwenden einen der folgenden generischen Installationsschlüssel.
 

  • Windows 8.1 Core – 334NH-RXG76-64THK-C7CKG-D3VPT
  • Windows 8.1 Core N – 6NPQ8-PK64X-W4WMM-MF84V-RGB89
  • Windows 8.1 Professional – XHQ8N-C3MCJ-RQXB6-WCHYG-C9WKB
  • Windows 8.1 Professional – GCRJD-8NW9H-F2CDX-CCM8D-9D6T9
  • Windows 8.1 Professional N – HMCNV-VVBFX-7HMBH-CTY9B-B4FXY

Mit diesen generischen Produktkeys können Sie Windows zwar installieren, jedoch ist das Windows-System danach nicht aktiviert.

Schritt 2: Aktivieren Sie Windows mit Ihrem Upgradelizenzschlüssel

Nach der Installation müssen Sie den verwendeten generischen Lizenzschlüssel gegen Ihren austauschen, um Ihr Windows zu aktivieren. Ignorieren Sie Tipps, die behaupten, dass Sie in der Registry oder in den Systemeigenschaften etwas ändern müssen. Windows bietet einen offiziellen Weg an, jedoch ist dieser etwas versteckt.

Wechseln Sie zur neuen Metro Startseite und tippen Sie „Funktionen“ ein. Es werden Ihnen Suchergebnisse präsentiert und Sie wählen „Programme und Funktionen“ aus. Als nächstes wählen Sie „Weitere Features mit einer neuen Edition von Windows beziehen“ und es öffnet sich ein neues Programmfenster. Dort klicken Sie auf „Ich habe bereits einen Produktkey“.

Im nächsten Fenster tippen Sie Ihren Upgradelizenzschlüssel ein. Windows wird nun das System Ihrem Lizenzschlüssel anpassen und entsprechend Funktionen installieren oder deinstallieren. Dieser Vorgang kann mehrere Minuten dauern.

Fazit

Mittlerweile ist es möglich eine saubere Neuinstallation von Windows 8.1 mit einer Windows 8 Upgradelizenz durchzuführen. Dies funktioniert aber nur, wenn Sie die dafür notwendigen generischen Produktkeys und das Vorgehen kennen.
