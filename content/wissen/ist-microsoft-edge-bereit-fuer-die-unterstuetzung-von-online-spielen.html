Microsoft hat eine neue Version des Edge Webbrowsers auf dem Markt gebracht. Die neue Version wurde auf Basis des Open Source Projekts Chromium, auf dem übrigens auch Google Chrome basiert, von Grund auf neu entwickelt. Aus diesem Grund wird Chrome Nutzern auch auffallen, dass sich beide Programme ähneln. Dies scheint aber von Microsoft beabsichtigt zu sein, damit sich Chrome Nutzer leichter mit der neuen Version zurechtfinden.

Microsoft hat sich Mühe gegeben gegen Google Chrome anzukämpfen, dass den Web-Browser Markt bis jetzt beherrscht. Der Internet Explorer hat sich in den letzten Jahren nicht behaupten können und das Unternehmen beschloss daher, ihn mit dem Start von Windows 10 im Jahre 2015 nicht mehr weiter zu entwickeln. Der ins Alter gekommene Web Browser wurde von Microsoft Edge abgelöst, mit dem Microsoft auch den schlechten Ruf des Webbrowsers loswerden wollte.

Microsoft will auch aktiver in der eSport-Szene und im online Gaming werden. Das Unternehmen hat aus diesem Grund unter anderem die Plattform Smash.gg aufgekauft, die Turniere in diesem Bereich anbietet. Wie Microsoft diese Plattform in Microsoft Edge integrieren bzw. unterstützen will, dazu schweigt sich das Unternehmen bisher aus. Es ist aber am wahrscheinlichsten, dass Microsoft die Plattform mit eigenen Inhalten füllen wird.

Microsoft Edge Add-Ons

Unterdessen werden die Add-Ons für Microsoft Edge weiter verbessert. Microsoft bietet dafür eine eigene Webseite an, auf der neue Add-Ons heruntergeladen werden können. Darunter befinden sich auch einige Online-Gaming Add-Ons, unter anderem für Minecraft. Auch die Zusammenarbeit mit den eigenen Spielen des amerikanischen Unternehmens soll in der neuen Version verbessert worden sein. Halo Infinite, Left 4 Dead und Forza Motorsport sollen von dem Webbrowser unterstützt werden. Die Unterstützung von grafisch anspruchsvollen Webseiten soll bei dem neuen Webbrowser schneller als bei der Konkurrenz arbeiten. Die Frage stellt sich, ob Microsoft gegen den übermächtigen Konkurrenten von Google Chrome ankommen kann. Der Webbrowser von Google hat einen Marktanteil von 66% und Microsoft erzielt mit einem Marktanteil von nur 3% abgeschlagen den fünften Platz unter den Webbrowsern.

Wenn wir die beiden Browser näher betrachten, sind sie in Bezug auf das Web-Design fast identisch. Microsoft hat alle ursprünglichen Design-Elemente ersetzt und mit runden Kanten eine saubere Benutzeroberfläche erschaffen. Es können nur geringe Unterschiede zwischen den beiden Browsern bei den Steuerelementen erkannt werden, die Suchleiste und die Symbole für die Erweiterungen, sowie Add-ons, befinden sich an der gleichen Stelle. Auch wenn Sie mit der rechten Maustaste neben den Registrierkarten klicken, öffnet sich das identische Registerkartenmenü. Wenn Sie also von dem Chrome Browser zu Edge wechseln, werden Sie beim täglichen Surfen kaum Unterschiede feststellen können.

Natürlich versucht Microsoft bei dem eigenen Web Browser auch seine Standard-Suchmaschine Bing unterzubringen, damit die neuen Benutzer nicht Google verwenden müssen. Die Benutzer bekommen aber die Möglichkeit ihre eigene Standard Suchmaschine zu verwenden.

Mehr Geschwindigkeit mit Edge!

Auch beim Geschwindigkeitsvergleich können keine großen Unterschiede festgestellt werden. Chrom erzielt ein bisschen bessere Ergebnisse in den Benchmarks, die aber im täglichen Gebrauch wahrscheinlich nicht zu erkennen sind. Microsoft Edge besitzt aber einen wesentlichen Vorteil gegenüber Chrome. Der Microsoft Webbrowser verbraucht deutlich weniger Ressourcen als sein Konkurrent. Auch wenn der Speicherbedarf heute nicht mehr entscheidend ist, kommt der Webbrowser von Microsoft in den meisten Fällen mit der Hälfte des Speichers aus. Wenn Sie also feststellen, dass Chrome auf ihrem Gerät zu viel Speicher in Anspruch nimmt, könnte Microsoft Edge Eine Alternative sein.

Um den Wechsel von Chrome zu Edge zu erleichtern, hat Microsoft einige Hilfen entwickelt. Nach der Installation kann ausgewählt werden, ob Edge die ganzen Informationen von Chrome übernehmen soll. Dazu gehören ihre Passwörter, die Lesezeichen, Adressen und alle weiteren Informationen die Chrome über Sie gesammelt hat. Dies ist ein nützliches Werkzeug für Benutzer, die von einem Web Browser auf den anderen wechseln möchten und sich nicht die Mühe machen möchten alle Informationen wieder neu eingeben zu müssen.
