ionas – Ihr Online Assistent hilft nicht nur täglich vielen Menschen bei der Lösung Ihrer Computerprobleme, sondern veröffentlicht auch jede Woche einen ionas-Quicktipp. Die ionas-Quicktipps sind kurze Youtube-Videos mit Ratschlägen, Meinungen oder praktischen Tipps rund um den Computer.

Mittlerweile hat ionas bereits über 50 Quicktipps produziert, weshalb man bestimmt auch eine gewisse qualitative Verbesserung in der Videoproduktion feststellen kann. Dank dieser Videos konnten wir in Summe bereits über 15.000 Zugriffe auf unserem Youtube-Kanal verbuchen.

Zur Feier dieser Zahl haben im letzten Teammeeting alle Mitarbeiter von ionas die Köpfe zusammengesteckt und die fünf besten Quicktipps zum Thema Windows ausgewählt. Schauen Sie doch mal rein. Ich bin mir sicher, dass für jeden Leser etwas dabei ist.

Gerne können Sie uns auch Anregungen schicken, zu welchem Thema Sie gerne mal einen Quicktipp sehen würden. Schreiben Sie uns dazu einfach einen Kommentar oder schicken Sie uns eine E-Mail an feedback@ionas.com.

Quicktipp 1: Automatischen Login unter Windows 7 und 8 aktivieren

Wussten Sie, dass es mehrere Wege gibt um sich automatisch in Windows anmelden zu lassen? In diesem ionas-Quicktipp zeigen wir Ihnen, welche Wege es zur Einrichtung des automatischen Windows-Logins gibt und welche Vor- und Nachteile die unterschiedlichen Wege haben.

Quicktipp 2: Wie Microsoft seine Kunden zu Windows 10 bringen will – Zwangsupgrade deaktivieren

Viele verzweifelte Kunden rufen bei uns an und beklagen eine langsame Internetverbindung. Der Schuldige ist häufig schnell gefunden. Windows lädt im Hintergrund fleißig mehrere Gigabyte an Daten für das Windows 10 Update herunter. Dieses verstopft die Internetleitung und macht das Surfen im Internet zur Geduldsprobe. In diesem Video zeigen wir Ihnen, wie Sie das Zwangsupgrade vermeiden.

Quicktipp 3: Windows Fenstermanagement

Wissen Sie genau, was passiert, wenn Sie ein Windows-Fenster an den rechten oder oberen Bildschirmrand ziehen? Wenn nicht, dann sollten Sie sich dieses Video ansehen. Wir zeigen Ihnen, welche Fähigkeiten das Fenster-Management von Windows alles mitbringt. So erfahren Sie z.B, wie man optimalerweise Windows Fenster anordnet und wie man diese Anordnung ändern bzw. selbst steuern kann.

Quicktipp 4: Der Task-Manager – Das verkannte Systemtool!

Der Task-Manager in Windows ist jedem Windows Benutzer ein Begriff. Hauptsächlich wird er zum Beenden von Programmen genutzt, die nicht mehr reagieren. Das der Taskmanager noch viele weitere Features mitbringt, wissen viele Anwender gar nicht. Welche weiteren Funktionen im Task-Manager stecken, zeigen wir in diesem Quicktipp.

Quicktipp 5: Verteilerliste in Windows Live Mail 2012

In diesem Quicktipp geht es darum, wie Sie in Windows Live Mail 2012 eine Verteilerliste erstellen.
Damit können Sie spielend einfach eine e-Mail an mehrere Empfänger gleichzeitig verschicken. Wenn Sie diese Fähigkeit einmal erlebt haben, werden Sie diese nie wieder vermissen wollen.
