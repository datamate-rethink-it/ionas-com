Rescue Stick

Prüfen, Retten und Installieren

Auf dem Rescue Stick "Hero" unserer Mutterfirma datamate befinden sich die Installationsdateien von 16 Windows- und Linux-Betriebssystemen sowie zwei Rettungssysteme. Der Stick kann Ihnen bei verschiedensten Notsituationen eine große Hilfe sein.

Mit Hero können Sie:

  • Ihr existierendes System von einem sicheren Medium aus auf Viren, Trojaner, Malware oder sonstige Schadsoftware prüfen
  • Wichtige Dateien von Ihrer Festplatte retten, wenn Ihr Computer nicht mehr startet
  • Mühelos eine Windows- oder Linux-Neuinstallation vornehmen

Dank des Rescue Sticks können Sie auch die Hilfe der ionas-Assistenten in Anspruch nehmen, wenn Ihr Rechner nicht mehr hochfährt. Starten Sie dazu den Computer einfach mit dem auf dem Stick enthaltenen Avira Rescue System oder einem Ubuntu Live-System. In dieser Umgebung können Sie die Fernwartungssoftware TeamViewer nutzen. So kann Ihnen Ihr Online Assistent bei der Datensicherung und Virenentfernung behilflich sein.

Ersparen Sie sich die Suche nach den passenden Installationsmedien oder einem freien USB-Stick. Mit dem Rescue Stick von datamate erhalten Sie ein denkbar vielseitiges Tool für Notsituationen aller Art!

Prüfen, Retten und Installieren - das ist Hero, der Rescue Stick mit Superkräften und hier können Sie Ihn ausprobieren.

Heute bestellt, morgen schon da

Den 32 Gigabyte Rescue USB-Stick gibt es für 49 € inklusive MwSt. und Versand auf Amazon. Prime-Kunden erhalten den Rescue Stick in aller Regel am Tag nach der Bestellung. Die Zahlung und der Versand erfolgen in gewohnter Amazon Qualität.

Darf es ein bisschen mehr sein?

Der Rescue Stick enthält die Installationsdateien von 16 Betriebssystemen sowie zwei Rettungssysteme:

  • Windows 10 (64 bit)
  • Windows 8.1 Home (32 und 64 bit)
  • Windows 8.1 Pro (32 und 64 bit)
  • Windows 7 Starter (32 bit)
  • Windows 7 Home (32 und 64 bit)
  • Windows 7 Professional (32 und 64 bit)
  • Windows 7 Ultimate (32 und 64 bit)
  • Ubuntu Desktop 16.04 LTS (32 und 64 bit)
  • Ubuntu Server 16.04 LTS (64 bit)
  • Avira Rescue System
  • Kaspersky Rescue Disk

Kein Windows-Product Key enthalten

Hero enthält keinen Product Key für die Aktivierung der Windows-Systeme. Ohne Aktivierung kann Windows nur 30 Tage getestet werden.

Ist Ihr Rechner mit einem Windows-System ausgeliefert worden, dann können Sie diesen Aktivierungsschlüssel wieder verwenden. Ansonsten müssen Sie einen Aktivierungsschlüssel separat erwerben.

Beliebig erweiterbar mit eigenen ISOs

Der Rescue Stick verfügt über mehrere Gigabyte an freiem Speicherplatz, auf dem Sie weitere Installationsmedien oder Rettungssysteme ablegen können. Der Rescue Stick erkennt Änderungen automatisch und stellt diese im Startmenü zur Verfügung. Ein manueller Eingriff ist dazu nicht notwendig. Damit können Sie den Rescue Stick sehr einfach nach Ihren Bedürfnissen erweitern.
